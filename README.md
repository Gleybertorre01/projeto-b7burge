🍔 B7Burger - Página de destino responsiva
Este projeto foi desenvolvido durante o curso da B7Web, com o objetivo de praticar e consolidar conceitos fundamentais de desenvolvimento front-end.

A proposta foi criar uma landing page de uma hamburgueria fictícia chamada B7Burger , aplicando boas práticas de estruturação e estilização.

🚀 Tecnologias utilizadas
HTML5
CSS3
Flexbox
Grade CSS
Consultas da mídia
Fontes do Google
🎯 Objetivo do projeto
Reforçar e aplicar na prática:

Estruturação semântica com HTML
Construção de layout com Flexbox
Organização de produtos com CSS Grid
Responsividade para diferentes tamanhos de tela
Uso de container commax-width
Boas práticas de organização de código
